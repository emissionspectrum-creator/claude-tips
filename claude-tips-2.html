基本觀念與工作流程

建立正確的 Claude 使用習慣，省時省 Token
1
雙視窗工作法 核心習慣

養成同時開兩個視窗的習慣，讓兩個工具各司其職：

Chat
Claude Chat
用來問問題、釐清觀念、討論方向。像是隨時可以問的顧問。
CC
Claude Code
專門用來開發程式，直接動手做事的工程師。
2
不要直接給程式碼

在專案還在構思階段，明確告訴 AI 不要輸出程式碼。Claude 很積極，稍微具體的需求就會直接開始寫，白白消耗大量 Token，而且方向還沒確認前寫出來的程式碼通常也用不上。

建議直接貼給 Claude Chat
In Claude chat, user prefers discussion and alignment over code. Do not provide code unless explicitly requested.
3
AI Alignment（對齊）

當你還沒把想法說清楚時，不要急著叫 AI 去做。先請 Chat 幫你「對齊」，讓 AI 把你的意圖反過來說給你聽，確認雙方理解一致後再進入執行。

對齊用 Prompt 我有個想法，但還沒想清楚，請幫我把這個計畫完善，並確認你理解我的目標。
4
寫兩份 Prompt

構思完成後，請 Claude Chat 幫你分別準備兩份：

① Chat 用
把專案背景、目標、限制條件都濃縮進去。每次開新對話時貼上，讓 AI 快速進入狀況。
② CC 用
更具體、更技術導向，直接描述要做什麼、用什麼架構。
5
何時開新視窗

對話越來越長時，AI 的「記憶」會開始混亂或不準確。以下情況建議開新 session：

  • 話題轉換，開始討論完全不同的功能
  • 感覺 AI 的回答開始「飄移」，不符合你的期待
  • 一個階段完成，進入下一個階段

開新 session 前，記得貼上你事先準備好的背景 prompt。

6
定期查詢用量

定期確認 API 用量，避免超支。可以在 Anthropic Console 查看每日用量與費用明細：

https://console.anthropic.com
02 /

Claude Code CLI 入門

從安裝到上手，一步一步來
1
如何安裝
問 Claude Chat 要如何安裝 Claude Code？

讓 Claude Chat 引導你操作終端機指令，最省事。

2
安裝結束後登入

在終端機輸入以下指令並完成登入：

claude

登入後，最基本的 Claude Code CLI 就能使用了。

3
兩個重要輔助工具
必要
Node.js
Claude Code 本身需要，也是很多前端工具的基礎。若未一起安裝，用自然語言請 CC 幫你完成。
強推
CC Viewer
查看產出檔案最方便的工具，推薦安裝 desktop app 版。
下載 CC Viewer
https://github.com/weiesky/cc-viewer/releases 建議下載桌面程式：CC Viewer Setup.exe
4
Claude Code 重要操作
操作用途
Shift + Tab切換到 Auto mode，讓 CC 自動連續執行，不需每步確認
/model切換使用的模型
/clear清空上下文
/resume繼續上一次中斷的對話
/exit離開 CC
5
CLI 基礎指令
指令用途
mkdir 資料夾名建立新資料夾
cd C:\資料夾路徑切換到指定資料夾
dir列出目前資料夾的內容
claude啟動 Claude Code
03 /

程式開發實作心得

讓開發流程更順暢的實用技巧
1
CC Viewer 的使用流程
  • 先用檔案總管建立新資料夾
  • 點開 CC Viewer 的 desktop app，進入該資料夾
  • 把資料夾當作獨立程式來思考
  • 不同資料夾負責不同任務
2
先在記事本寫 Prompt，再貼進 CC

1. 不要在 CC 裡面邊想邊打。先在記事本或任何文字編輯器把你要說的話寫清楚，確認沒問題了，再一次貼進去。這樣思路更清晰，也方便修改與重用。

2. 我們習慣按ctrl+c/v鍵來複製貼上，或按 esc來取消，都可能不經意地中斷cc viewer裡正在進行的claude code工作。

3
優先要求 Web UI 非工程背景必看
  • 直接用瀏覽器操作，不需要懂指令
  • 有按鈕、有輸入框、有結果區
  • 對非工程背景使用者比較友善
4
要求做成 .bat 檔啟動 Windows 用戶

如果是在 Windows 上使用，.bat 檔很實用。請 CC 做一個啟動 Web UI 的 .bat 檔，可以省下很多操作時間。

5
遇到不懂的名詞，丟回 Chat 問

CC 執行過程中會出現很多你不熟悉的技術詞彙。不要硬猜，直接複製貼到 Chat 問：

建議問法 這個詞是什麼意思？有幾種做法？各自的優缺點是什麼？

有時候你會發現，某個選項可以同時達成兩種你想要的功能。這種收穫往往來自多問一句。

6
請 AI 上網查詢類似經驗

Claude Chat 有聯網能力。遇到不確定的技術選型或工具，可以直接說：

聯網查詢範例 請幫我查查有沒有其他人做過類似的事，有什麼常見的坑或推薦做法。

這比你自己 Google 再消化快很多。

7
不用二選一，可以同時擁有兩種功能

新手常以為 AI 問 A 或 B，就只能選一個。但很多時候可以請 AI 設計折衷方案，同時滿足兩種需求。

其他知識

API 差別、GPU 選擇、進階觀念
1
API 與 Claude Pro 的差別
Claude Pro 訂閱制
  • 在 claude.ai 網站上使用
  • 按月付費，有訊息數量上限
  • 主要用於網站互動
Claude Code API 按量計費
  • 在你電腦本地運行
  • 按實際用量計費，無上限
  • 有 Pro 仍需另外儲值 API 額度

API 有兩種模式：

一般 API

即時回應

你問它馬上答，適合互動式開發。

批次 API

非同步 · 省 50%

打包送出，費用省一半，適合大量文件處理、批次改寫等不需要即時結果的工作。

2
GPU 的選擇 本地跑模型

如果未來想在本地跑 AI 模型（語音、圖像、語言模型），建議買 NVIDIA 顯示卡，不要買 AMD。

原因 大多數 AI 工具的 GPU 加速基於 NVIDIA 的 CUDA 技術。AMD 雖然有對應方案，但支援度、穩定性、社群資源都差很多，踩坑機率高。
3
進階觀念：優化、Skills 與 Hooks

剛開始不需要馬上學很深入，但可以先知道這些東西存在。日後隨著使用量增加，自然會有更多探索的動力。
